Лабораторная работа №4

----------------------------------------------------------------------------------------------------------

Суть этой лабораторной - научиться писать модульные (юнит) тесты и проверять сложную условную логику.


Задача: Есть класс Converter с методом do(x). Внутри него куча условий (if-elif-else), которые в зависимости от числа x возвращают разные значения, а при x = 0.0 выбрасывают исключение ValueError.

Решение задачи: Написать тесты на unittest, чтобы убедиться, что каждая ветка этого алгоритма работает как задумано.


Покрытие всех веток, нужно проверить каждое условие (больше 100.7, от 0 до 100.7, отрицательные и т.д.).

Граничные значения (Boundary values): Необходимо проверить числа ровно на стыке диапазонов (100.7 и 100.6, -30.4 и -30.5). Тут чаще всего могут прятаться баги (например, ошибка > вместо >=).

---------------------------------------------------------------------------------

Для проверки исключений используется assertRaises(ValueError), чтобы убедиться, что при 0.0 программа действительно падает, а не просто возвращает 0.
